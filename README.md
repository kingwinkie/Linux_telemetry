What this is.

It's a way to get telemetry data out of nr2003 running in wine into Linux.

It also lets you get data in to change the nr2003.exe with data from Linux into wine/nr2003.

The important bit is the changes in the tsample.exe. This will compile under linux and run under wine. This also should allow you to have more then one stream from the shared memory.

The nr2003_qt is just a simple display/button push to test the data in and out.

This seems to be working for me.

It might work for you (lol)

There is the compiled files That you can try. If not you can edit the source to fix.

Read the readme.md's on compiling and using. There are also some wine troubleshooting and using this in Lutris
